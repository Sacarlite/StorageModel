
# Warehouse  Console App

**Разработчик:**  
Боковой Владислав

## Описание

Консольное .NET приложение для управления складом, позволяющее добавлять паллеты и коробки, вычислять сроки годности, вес и объём, а также выводить отсортированные данные.

Поддерживает:
- Ручной ввод данных
- Генерацию случайных данных
- Загрузку конфигурации из JSON
- Валидацию входных данных

Приложение написано по принципам чистой архитектуры, разделено на слои:
- Domain — доменные модели и интерфейсы
- Infrastructure — DTO, репозитории, EF Core контекст
- Application — бизнес-логика (сервисы)
- Presentation — консольный UI, меню, навигация
- Resources — конфигурационные файлы

---

##  Архитектура

### Слои:
| Слой | Что содержит |
|------|--------------|
| **Domain** | Модели: `Pallet`, `Box`, интерфейсы: `IStorageItem`, `IHasWeight`, `IContainer` |
| **Infrastructure** | DTO (`PalletDTO`, `BoxDTO`), `WarehouseDbContext`, `IStorageRepository`, реализация репозиториев |
| **Application** | Сервис `IStorageService` / `WarehouseService` с логикой сортировки |
| **Presentation** | Консольное меню, обработка пользовательского ввода, валидация |
| **Resources** | Файлы конфигурации (`config.json`) |

###  Маппинг
Для маппинга между DTO и Domain используется **Mapster**:
```csharp
TypeAdapterConfig<BoxDTO, Box>.NewConfig()
    .Map(dest => dest.ExpirationDate, src => BoxMapper.MapExpirationDate(src));
```

## Возможности

1. **Добавление паллеты вручную**
2. **Добавление коробок к выбранной палете**
3. **Генерация тестовых данных**
   - Настройка через `config.json`
4. **Вывод информации в виде таблиц:**
   - Все паллеты, сгруппированные по сроку годности, отсортированные по весу
   - Топ-3 паллеты с наибольшим сроком годности, отсортированные по объему
5. **Валидация ввода**
   - Размеры должны быть положительными
   - Даты в формате `yyyy-MM-dd`
   - Коробка не может превышать размеры паллеты

## Требования (ТЗ)

> Разработать консольное .NET приложение для склада, удовлетворяющее следующим требованиям:

### 1. **Иерархия классов**
#### Коробка
- ID
- Ширина, высота, глубина
- Вес
- Срок годности или дата производства (+100 дней)
- Объём = ширина × высота × глубина

#### Паллета
- ID
- Ширина, высота, глубина
- Базовый вес = 30 кг
- Коллекция коробок
- Срок годности = минимальный срок годности среди коробок
- Общий вес = 30 кг + сумма весов коробок
- Общий объём = ширина × высота × глубина + сумма объёмов коробок
- Коробки не могут выходить за пределы паллеты по ширине и глубине

---

### 2. **Функциональность приложения**

#### Добавление объектов:
- Добавить паллету
- Добавить коробку к паллете
- Сгенерировать случайные данные

#### Вывод в консоль:
- **Список паллет**, сгруппированный по сроку годности, внутри групп — отсортированный по весу
- **Топ-3 паллеты** с наибольшим сроком годности, отсортированные по возрастанию объема

#### Ввод данных:
- Поддержка ручного ввода
- Генерация данных из конфигурации
- Валидация ввода:
  - Положительные числа
  - Корректные даты
  - Размеры коробки ≤ размеров паллеты
